# Scoop bucket

[Scoop](https://scoop.sh) manifests for [live-serve](https://github.com/NguyenTruong354/live-serve).

```
scoop bucket add nguyentruong354 https://github.com/NguyenTruong354/scoop-bucket
scoop install live-serve
```

Upgrade with `scoop update live-serve`. A scheduled job updates the manifest when a new release comes out.
